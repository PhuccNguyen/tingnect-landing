# TingNect - Build for Billions

## Hướng dẫn SEO để search engine tìm thấy website

### Sitemap và SEO đã được tối ưu:

1. **Sitemap.xml**: `/sitemap.xml`
   - Tất cả trang đã được liệt kê với priority và changeFrequency
   - Homepage priority: 1.0 (cao nhất)
   - ID page priority: 0.9 (cao)
   - Products page priority: 0.8
   - Contact page priority: 0.7
   - Privacy page priority: 0.3

2. **Robots.txt**: `/robots.txt`
   - Cho phép tất cả search engines crawl
   - Chặn các bot xấu (SemrushBot, AhrefsBot)
   - Ưu tiên Google và Bing với crawl-delay thấp

3. **Meta Tags đã tối ưu**:
   - Title: "TingNect - Build for Billions" (100% chính xác)
   - Description tối ưu cho keyword "TingNect"
   - Keywords bao gồm nhiều variation của "TingNect"
   - OpenGraph và Twitter Cards

4. **Structured Data (JSON-LD)**:
   - Organization schema với thông tin TingNect
   - Website schema
   - WebPage schema
   - Event schema cho sự kiện TingNect

### Để search "TingNect" tìm thấy website:

1. **Submit sitemap lên Google Search Console**:
   - Đăng ký Google Search Console
   - Submit sitemap: `https://tingnect.com/sitemap.xml`
   
2. **Submit lên Bing Webmaster Tools**:
   - Đăng ký Bing Webmaster Tools
   - Submit sitemap tương tự

3. **Verification codes đã sẵn sàng**:
   - Google: `tingnect-build-for-billions-google-verification`
   - Bing: `tingnect-bing-verification`

4. **Keywords đã tối ưu**:
   - "TingNect" xuất hiện trong title, meta description, keywords
   - "TingNect Build for Billions", "TingNect Vietnam", "TingNect Web3"
   - Nhiều variation của brand name

### Files SEO đã tạo/cập nhật:
- ✅ `/src/app/sitemap.ts` - Dynamic sitemap
- ✅ `/public/robots.txt` - Search engine instructions  
- ✅ `/src/app/manifest.ts` - PWA manifest
